Interactive Components Guide

Learn how to use the interactive features built into Wealth Bridge.

🔲 Modals & Dialogs

Use modals for confirmations, forms, and overlays.

HTML Structure

No additional code needed! Just use the data attributes above.

📝 Form Handling

All forms are automatically handled and validated. No extra code needed!

Supported Forms

  • Login Form - Email & password with remember-me
  • Signup Form - Registration with password strength indicator
  • Deposit Form - Payment with fee calculation
  • Withdrawal Form - Money transfer with net amount display
  • Profile Form - User details update
  • Password Change Form - Secure password update
  • Contact Form - Message submission
  • Support Tickets - Issue reporting

Built-in Validations

  • ✓ Email format validation (RFC standard)
  • ✓ Password strength checking (8+ chars, uppercase, number, special)
  • ✓ Phone number validation
  • ✓ Currency amount validation with minimums
  • ✓ Credit card validation (13-19 digits)
  • ✓ CVV validation (3-4 digits)

Real-Time Features

  • ⚡ Password strength indicator (0-4 scale)
  • ⚡ Dynamic fee calculation for deposits/withdrawals
  • ⚡ Net amount display
  • ⚡ Remember-me functionality
  • ⚡ Form loading states

📊 Charts & Visualizations

Canvas-based charts for portfolio performance, asset allocation, and more.

Supported Charts

  • Line Charts - Portfolio value over time
  • Pie Charts - Asset allocation breakdown
  • Bar Charts - Quarterly performance comparison
  • Candlestick - Price history (planned)

HTML Structure

<canvas data-chart="portfolio" width="400" height="300"></canvas> <canvas data-chart="assets" width="400" height="300"></canvas> <canvas data-chart="performance" width="400" height="300"></canvas>

Automatically Rendered On

  • Portfolio page - `[data-chart="portfolio"]`
  • Investments page - `[data-chart="assets"]` and `[data-chart="performance"]`
  • Dashboard - `[data-chart="price-history"]`

🔗 Integration Guide

All features are automatically initialized. To use them:

1. For Modals

<!-- Button to open --> <button data-modal-open="my-modal">Open</button> <!-- Modal element --> <div data-modal="my-modal" style="display: none;"> <div class="modal-content"> Content here <button data-modal-close>Close</button> </div> </div>

2. For Forms

Just use standard HTML form elements. Validation and submission are handled automatically!

3. For Charts

<canvas data-chart="portfolio" width="400" height="300"></canvas> <!-- Chart automatically rendered -->

4. Custom JavaScript (Optional)

// Show notifications UIInteractions.showNotification('Success!', 'success', 3000); // Manually open/close modals UIInteractions.openModal('my-modal'); UIInteractions.closeModal('my-modal'); // Run validations FormHandler.validate.email('user@example.com'); FormHandler.validate.passwordStrength('Pass123!@');

❓ FAQ

Q: Can I use multiple modals at once?
A: Yes! Each modal is independent. Use unique data-modal values for each.
Q: Do forms submit to a backend?
A: Currently, forms use localStorage for MVP. For production, connect apiService.js to your backend API.
Q: Can I customize chart colors?
A: Yes! Edit chart-renderer.js and modify the backgroundColor and borderColor properties.
Q: How do I add more forms?
A: Add new methods to the FormHandler class in forms-handler.js following the existing pattern.
